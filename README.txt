第8回 小課題②「トップページ」のスターター

【入っているもの】
  index.html  … トップページの骨組み（設計図の「上から順」に書き換える）
  style.css   … 色・余白の変数と、並べ方、スマホ対応（★のところを、自分で決める）

【使い方】
  1. 展開してできた site フォルダを、作業用フォルダの中に置く
     （Windowsで「すべて展開」すると、フォルダの中に、もう1つ site ができることがある。中の site を使う）
  2. VSCode でフォルダを開き、index.html を Live Preview で表示する
  3. 設計図（用紙）を見ながら、index.html の文章と部品を書き換える
  4. style.css の ★ を、自分で決めた色・フォント・余白に変える

【公開するとき】
  サーバーの public_html の中に、site フォルダごと置く
  → https://class.tama.net/u/自分のID/site/index.html
  （小課題①の profile.html と style.css は、public_html の直下にあります。上書きしないこと）

【注意】
  このスターターは、見本（授業用の架空のお店）と同じ骨組みです。
  色・フォント・文章・画像は、自分のサイトに合わせて、必ず、自分で決めてください。
